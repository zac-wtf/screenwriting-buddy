# 使用示例

以下内容是为说明技能行为编写的原创示例，不是实际对话记录、用户评价或传播效果证明。实际合作会随你的素材与选择变化。

[返回项目首页](../README.md)

## 1. 有点子，先做一个影响方向的选择

**可以这样输入：**

```text
用 $screenwriting-buddy 和我发展一个独立剧情短片。
点子是：一个能听见物品说话的维修工，收到一台不肯开口的旧录音机。
我想让结尾有一点温暖。先问一个关键问题，给出建议。
```

**合作示范：**

> 我建议把“它不肯开口”变成“它不敢再播放”，让观众先好奇，再理解它在保护什么。
>
> 先定一个关键点：录音机是怕泄露秘密，还是怕最后一段录音再也播不出来？我推荐后者，更贴近你想要的温暖结尾。

你选定方向后，就可以要求“先写开场”或“给我一版大纲”。无需先填完人物小传、世界观和全部配角。

## 2. “不好看”，先找出戏没有变化的地方

**可以这样输入：**

```text
用 $screenwriting-buddy 帮我改这场戏。我觉得不好看。
保留设定：主角必须拿回自己的录音机；店主因为欠款不肯归还。
先诊断，再做局部修改。

主角：还给我。
店主：钱没付，不还。
主角：我真的很需要。
店主：说了不还。
主角：求你了。
店主：没用。
```

**诊断示范：**

> 从“我真的很需要”开始，双方都没有改变策略，观众已经知道接下来的回答。可以保留店主坚持收钱，让主角提出一个有代价的新办法，使处境发生变化。

**局部改写示范：**

```text
主角摸遍口袋，把零钱推到柜台上。

店主：还差四百。

主角摘下腕表，放在零钱旁。

主角：这个先押你。明天拿钱换。

店主看向表带上磨掉的半截名字。

店主：你爸留的，也舍得？

主角盯着柜台里的录音机。

主角：表明天还能赎。他的声音，我今天就想听。
```

这里增加了一个可以表演的选择：主角愿意付出什么。店主是否接受、人物关系如何变化，仍需结合前后文决定。新增父亲与腕表的细节属于候选方案，接入全稿前由作者确认。

## 3. 连续短剧：当前这集先有结果

**可以这样输入：**

```text
用 $screenwriting-buddy 推演下一集。
已定规则：维修工能听见物品说话，别人听不见；他不能读取人的记忆。
上一集结尾：他答应修复一台旧录音机。
这集需要推进修复，也留下下一集的问题。先给事件方案。
```

**事件方案示范：**

> 他发现磁带断在一句话中间，想接回去，录音机却一直阻止。交谈后才知道，先前几次播放都在磨损断口，它怕最后一点声音也被弄丢。
>
> 他改变方案，先固定磁带、尝试转录。这一集让他成功保住一小段声音，兑现修复的进展。听清后，他发现这段留言的收件人不是送修的顾客；下一集的问题来自这个新信息：顾客究竟要把声音带给谁？

是否采用这项录音修复设定，需要结合故事规则与所需真实程度继续校准。这里展示的是：让行动产生结果，再由结果打开后续；不把播放到一半直接切黑作为唯一的追更办法。

## 使用时可以补充什么

提供你已经确定的时长、类型、结尾、必须保留的情节，以及本次只想讨论还是直接写稿。没有确定的内容可以留给对话推进。

已有项目请附上当前有效稿或简短状态记录，方便搭子沿用已定方向。
